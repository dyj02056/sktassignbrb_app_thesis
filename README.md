# ML Play

> 외우지 말고, 이해하세요.

머신러닝의 핵심 개념 6가지를 **이야기 + 3D 체험**으로 배우는 인터랙티브 웹 앱.

---

## 이 앱은 무엇인가요

**ML Play**는 머신러닝을 처음 배우는 사람이 어려운 개념을 **이야기로 이해하고, 직접 3D로 만져보며 체험**하는 학습 앱입니다.

논문 「LLM은 새로운 개념을 어떻게 학습하는가: 공식 중심 설명과 스토리 중심 설명의 효과 비교」(정성원, 2026)의 결과를 실제로 사용합니다. 논문에서 **스토리 중심 설명이 재설명·비유 생성에 더 유리**하다는 탐색적 발견을, 이 앱은 **"이야기 → 3D 체험"** 구조로 구현했습니다.

---

## 누구를 어떻게 돕나요

**머신러닝을 처음 배우는 사람**이 어려운 개념을 만났을 때, 이 앱이 **그 개념을 이야기로 들려주고, 직접 3D로 움직여 보게 하며, 핵심을 정리**해 줍니다.

## 챕터 6개

| # | 개념 | 이야기 (일상 비유) | 3D 체험 |
|---|---|---|---|
| 1 | 경사하강법 | 안개 낀 산에서 내려오는 등산객 | 3D 손실 표면 위 공이 굴러내려감 |
| 2 | 역전파 | 시험 성적표를 거꾸로 짚는 학생 | 4단계 (순전파 → 오차 → 역전파 → 갱신) |
| 3 | 과적합 | 기출만 외운 학생 | 손전등이 기출만 비춤, 새 문제는 그림자 |
| 4 | 선형 회귀 | 키와 몸무게의 관계 | 3D 산점도 + 회귀 직선 |
| 5 | 로지스틱 회귀 | 시험 합격 예측 | 3D S자 곡선 + 합격/불합격 점 |
| 6 | 신경망 | 여러 전문가의 릴레이 | 손글씨 "5" 인식 과정 (은닉층) |

각 챕터는 **개념 → 이야기 → 직접 해보기 → 핵심 요약** 4단계로 구성됩니다.

## 실행 방법

### 방법 1: 공개 URL (가장 간단)

https://sktassignbrb-app-thesis.vercel.app/

브라우저에서 위 주소를 열면 바로 실행됩니다.
- 로그인, 회원가입, 인증 없음
- 추가 설치 없음

### 방법 2: 로컬에서 실행

1. 저장소를 클론 또는 ZIP 다운로드

   git clone https://github.com/dyj02056/sktassignbrb_app_thesis.git

2. 폴더로 이동

   cd sktassignbrb_app_thesis

3. index.html을 브라우저에서 열기
   - 더블클릭 또는
   - file:///.../index.html 경로로 열기

**참고**: 3D 렌더링(Three.js)은 로컬 lib/ 폴더에 포함되어 있어 인터넷 없이도 작동합니다. 폰트만 Google Fonts CDN을 사용하므로 인터넷이 필요합니다.

## 사용한 기술

| 기술 | 용도 |
|---|---|
| HTML / CSS / JavaScript | 기본 구조 |
| Three.js (r128) | 3D 시각화 (경사하강법, 역전파, 과적합, 회귀, 신경망) |

**프레임워크 없음.** 순수 HTML/CSS/JS + Three.js만 사용.

## 논문과의 연결

이 앱은 다음 논문의 결과를 실제로 사용합니다:

> **정성원 (2026).** LLM은 새로운 개념을 어떻게 학습하는가: 공식 중심 설명과 스토리 중심 설명의 효과 비교.

**논문의 탐색적 발견**:
- 재설명 과제에서 스토리 중심 설명이 공식 중심 설명보다 높은 점수 (5.6 vs 4.7)
- 비유 생성 과제에서도 스토리 중심 설명이 더 높음 (5.2 vs 4.8)
- 응용 문제에서는 천장 효과로 차이 검증 실패

**앱에서의 사용**:
- 모든 개념을 **"이야기(스토리)"로 먼저 소개**
- 이야기 직후 **3D 체험**으로 연결 (재설명·비유의 확장)
- 논문이 "스토리가 이해를 돕는다"는 결과를 실제 앱 구조로 구현

## 앱 사용 흐름

1. **타이틀 화면** — ML PLAY + START
2. **안내 화면** — 논문 제목 + "나쁜 답변 vs 좋은 답변" 비교
3. **챕터 선택** — 6개 챕터 중 선택
4. **각 챕터**:
   - ① 개념 — 한 줄 정의
   - ② 이야기 — 일상 비유 + 이미지
   - ③ 직접 해보기 — 3D 체험 + 슬라이더 + 실행/정지/초기화
   - ④ 핵심 요약 — 4줄 정리
5. **다른 챕터 보기** — 챕터 선택으로 돌아감

**팁**: 화면 아무 곳이나 클릭하면 타이핑이 즉시 완성됩니다. 기다리기 싫으면 클릭하세요.

## 재현 방법

1. 브라우저(Chrome, Edge, Firefox, Safari)를 엽니다.
2. 공개 URL 또는 로컬 index.html을 엽니다.
3. START를 클릭합니다.
4. 안내 화면을 읽고 [다음]을 클릭합니다.
5. 챕터 1~6 중 하나를 클릭합니다.
6. 각 챕터에서:
   - 개념과 이야기를 읽습니다.
   - [직접 해보기]에서 슬라이더를 움직이고 [실행]을 누릅니다.
   - 3D 화면을 마우스로 드래그해 회전합니다.
   - [다음]을 눌러 요약을 봅니다.

## 확인 방법 (통과 확인)

| 확인 항목 | 방법 |
|---|---|

| 슬라이더 반영 | 슬라이더를 약/적당/강으로 움직이고 [실행] |
| 로그인 없이 열림 | 시크릿 창에서 URL 접속 |

## 알려진 제한

- **모바일**: 3D 캔버스가 작게 보일 수 있음. PC 환경 권장.
- **한글 폰트**: VT323은 영어 폰트. 한글은 시스템 폰트로 표시됨.
- **성능**: 3D 렌더링이 계속 돌아가므로 저사양 기기에서는 끊길 수 있음.
- **인터넷**: 폰트(Google Fonts)는 인터넷 필요. 3D는 로컬이라 오프라인 가능.
