# Structure — ML Play 프로젝트 구조와 기능

**비전공자도 이해할 수 있게 정리한 문서입니다.**

---

## 1. 이 앱은 무엇인가요

**ML Play**는 머신러닝(인공지능의 한 분야)을 처음 배우는 사람이 어려운 개념을 **이야기와 3D 체험**으로 배우는 앱입니다.

### 비유로 설명하면

- **책으로 배우기**: 어려운 공식과 용어가 가득 → 지루하고 이해 안 됨
- **ML Play로 배우기**: 산, 시험, 손전등 같은 **일상 이야기**로 먼저 이해 → **3D로 직접 만져보며** 체험 → 머릿속에 남음

### 앱을 열면

1. **타이틀 화면**: "ML PLAY" + "START" 버튼
2. **안내 화면**: 논문 제목 + "나쁜 답변 vs 좋은 답변" 비교
3. **챕터 선택**: 6개 챕터 중 고르기
4. **각 챕터**: 개념 → 이야기 → 3D 체험 → 요약

---

## 2. 6개 챕터 (무엇을 배우나)

| # | 개념 | 이야기 (일상 비유) | 3D 체험 |
|---|---|---|---|
| 1 | 경사하강법 | 안개 낀 산에서 내려오는 등산객 | 3D 그릇 표면 위 공이 굴러내려감 |
| 2 | 역전파 | 시험 성적표를 거꾸로 짚는 학생 | 3D 막대 6개 (4단계) |
| 3 | 과적합 | 기출만 외운 학생 | 손전등이 기출만 비춤 |
| 4 | 선형 회귀 | 키와 몸무게의 관계 | 3D 산점도 + 직선 |
| 5 | 로지스틱 회귀 | 시험 합격 예측 | 3D S자 곡선 |
| 6 | 신경망 | 여러 전문가 릴레이 | 손글씨 "5" 인식 |

### 각 챕터의 4단계

1. **개념** — 한 줄 정의 (타이핑 이펙트)
2. **이야기** — 일상 비유 텍스트 + 이미지
3. **직접 해보기** — 3D 체험 + 슬라이더 + 실행/정지/초기화
4. **핵심 요약** — 4줄 정리

## 3. 앱의 특징

### 3.1 CLI (터미널) 톤

옛날 컴퓨터 터미널처럼 생겼습니다.

- 검정 배경 + 초록 글씨
- `C:\ML_PLAY>` 프롬프트
- 픽셀 폰트 (VT323)
- CRT 스캔라인 효과 (브라운관 TV 느낌)

### 3.2 타이핑 이펙트

글자가 **한 글자씩** 나타납니다.

- 기다리기 싫으면 **화면 아무 곳이나 클릭** → 즉시 완성
- 다음 화면은 다시 정상 타이핑

### 3.3 3D 체험

각 챕터마다 **진짜 3D 화면**이 나옵니다.

- **마우스 드래그**로 시점 회전
- **슬라이더**로 값 조절
- **[실행]** 누르면 애니메이션
- **[정지]** / **[초기화]** 버튼

### 3.4 이야기 → 체험 연결

논문의 결과("스토리가 이해에 유리")를 실제로 구현:

- 모든 개념을 **이야기로 먼저** 소개
- 이야기 직후 **3D 체험**으로 연결
- "아, 이게 그거구나" 바로 이해

- **lib/** = 3D TV 같은 도구

## 5. 어떻게 작동하나 (비전공자용)

### 5.1 앱을 열면

1. 브라우저가 index.html을 읽음
2. style.css로 디자인 적용
3. script.js가 화면 전환 준비
4. chapter1~6.js가 챕터 데이터 준비
5. lib/three.min.js가 3D 준비

### 5.2 START를 누르면

1. script.js의 goTo('screen-intro') 실행
2. 안내 화면으로 전환
3. 타이핑 이펙트로 글자 하나씩 표시

### 5.3 챕터를 고르면

1. openChapter(1) 실행
2. chapters/chapter1.js의 데이터를 읽음
3. 화면 4단계 (개념 → 이야기 → 체험 → 요약) 순차 표시
4. 체험 단계에서 setupGD3D() 실행 → 3D 씬 생성

### 5.4 [실행]을 누르면

1. runGD3D() 실행
2. 3D 공이 곡선을 따라 이동
3. 슬라이더 값에 따라 속도/결과 다름

## 6. 사용한 기술 (쉬운 설명)

| 기술 | 무엇인가 | 어디에 쓰였나 |
|---|---|---|
| **HTML** | 웹페이지의 뼈대 | index.html |
| **CSS** | 디자인 (색, 폰트, 여백) | style.css |
| **JavaScript** | 움직임과 상호작용 | script.js, chapters/*.js |
| **Three.js** | 3D 그림을 그리는 도구 | 각 챕터 체험 |
| **OrbitControls** | 마우스로 3D 회전 | 각 챕터 체험 |
| **Canvas API** | 그림을 그리는 도구 | 챕터 6 손글씨 "5" |
| **Google Fonts** | 폰트 (VT323) | 전체 CLI 톤 |

**프레임워크 없음**: React, Vue 같은 복잡한 도구 안 씀. 순수 HTML/CSS/JS + Three.js만.

## 7. 논문과의 연결

### 논문 (10번 과제)

> **정성원 (2026).** LLM은 새로운 개념을 어떻게 학습하는가: 공식 중심 설명과 스토리 중심 설명의 효과 비교.

**논문의 발견**:

- 스토리 중심 설명이 **재설명** 과제에서 더 높은 점수 (5.6 vs 4.7)
- **비유 생성** 과제에서도 스토리 중심이 더 높음 (5.2 vs 4.8)
- 응용 문제는 천장 효과로 차이 검증 실패

### 앱에서의 사용

- 모든 개념을 **"이야기"로 먼저** 소개 (논문의 "스토리 우위" 반영)
- 이야기 직후 **3D 체험**으로 연결 (재설명·비유의 확장)
- 논문이 "스토리가 이해를 돕는다"는 결과를 실제 앱 구조로 구현
