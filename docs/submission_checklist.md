## 짧은 확인 방법 (BRB-C13)

**어디서 확인하나요**: https://sktassignbrb-app-thesis.vercel.app/

**무엇을 하나요 (3단계 이내)**:

1. URL을 새 시크릿 창에서 연다 → 타이틀 화면 (ML PLAY)
2. START 클릭 → 안내 화면 (논문 제목 + 비교 박스) → [다음] 클릭
3. 챕터 선택 → 원하는 챕터 클릭 → 개념 → 이야기 → [직접 해보기] → 슬라이더 움직이고 [실행] 클릭

**무엇이 보이면 통과**:

- 타이틀에 "ML PLAY" ASCII 아트 + "외우지 말고, 이해하세요"
- 안내 화면에 논문 제목 + "나쁜 답변 / 좋은 답변" 비교 박스 + 강아지 이미지 2개
- 챕터 선택에 6개 항목 (경사하강법 ~ 신경망)
- 각 챕터에서 3D 화면이 나오고, 마우스 드래그로 회전 가능
- 슬라이더를 움직이면 3D 화면이 반응
- [실행] 클릭 시 4단계 애니메이션

**안 될 때**:

- 3D가 안 나오면 → 브라우저를 최신 Chrome/Edge로 열기 (WebGL 지원 필요)
- 한글이 깨지면 → 폰트 로딩 문제, 새로고침
- 슬라이더가 안 움직이면 → 페이지 새로고침

## AI와 나의 판단 3줄 (BRB-C14)

**① AI에게 맡긴 일**:

- 3D 시각화 코드 생성 (Three.js 씬, 카메라, 조명, 노드/막대/곡선)
- 각 챕터의 스토리 텍스트와 일상 비유 초안 작성
- CSS 스타일 (CLI 톤, CRT 스캔라인, 슬라이더, 범례)
- 타이핑 이펙트 로직 (typeText, 클릭 스킵)
- 배포 (GitHub, Vercel) 및 12번 사이트 연결 코드

**② 내가 직접 판단한 일**:

- 앱의 최종 문장과 사용자 할 일 3가지 확정
- 채점 기능 제거 결정 (사용자 심리 부담)
- 6개 챕터 선정 (ML 핵심 개념)
- 각 챕터의 이야기 주제 (산, 시험, 손전등, 키·몸무게, 합격, 릴레이)
- 스토리 이미지 8개 제작
- 앱 이름 최종 결정 (ML Play)
- 12번 사이트 대표작 문구

**③ AI 제안을 따르지 않은 일**:

- **채점 기능**: AI가 처음에 논문 채점 기준을 앱에 넣자고 제안. 사용자가 "점수 매기면 싫어할 것 같다"고 거부 → "핵심 요약"으로 대체.
- **3D 도입 시점**: AI는 6개 챕터 다 만든 후 3D 도입을 추천. 사용자가 "3D로 하고 싶다"고 해서 처음부터 3D.
- **새(bird) 비유**: AI가 챕터 3에서 "새가 기출만 쫓아다님" 비유를 만들었으나, 사용자가 "새와 새 문제의 상관관계가 이해 안 됨"이라고 지적 → 손전등 비유로 교체.
