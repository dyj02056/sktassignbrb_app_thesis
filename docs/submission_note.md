## 7. 개발 과정 주요 이벤트

### 7.1 타이핑 이펙트 문제

- 문제: 챕터 선택 화면에 타이핑 없음, 클릭 시 다음 화면도 스킵
- 원인: skipped가 전역으로 남아있음
- 해결: typeText 시작 시 skipped 초기화, closest('button') + closest('.chapter-item') 예외

### 7.2 3D 색 대비 문제

- 문제: 표면과 공이 같은 초록이라 안 보임
- 해결: 표면 채우기 제거, 와이어프레임만 (시안), 공(초록), 경로(주황)

### 7.3 3D 좌표 매핑 문제

- 문제: 경사하강법에서 공이 산꼭대기에서 시작
- 원인: toHeight: -loss * 8 + 2 (loss 작을수록 높음)
- 해결: toHeight: loss * 8 - 2 (loss 작을수록 낮음)

### 7.4 손전등 방향 문제

- 문제: 손전등이 위에서 아래로, 기출/새 문제 구분 안 됨
- 해결: 손전등을 비스듬히 옆에서, 그림자 castShadow, 마젠타 새 문제

### 7.5 새 문제 생성 방식

- 문제: 새 문제가 하늘에서 날아오는 게 이해 안 됨
- 해결: 중간 지점에 페이드 인 → 빛 밖으로 밀려남

### 7.6 챕터 6 슬라이더 반영 문제

- 문제: 슬라이더 움직여도 3D 화면이 그대로
- 해결: 은닉층 노드 개수 1/3/5/7개로 변화 + 출력 라벨 opacity 변화

### 7.7 체험 화면 타이핑 없음

- 문제: 체험 화면(renderExperiment)에 타이핑 없음
- 해결: 순차 타이핑 (라벨 → intro → formula → legend → slider label → slider desc)
